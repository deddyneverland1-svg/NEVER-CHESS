# NEVER CHESS — Android prototype 0.2.0

## Included
- Dark NEVER CHESS home screen.
- Interactive 8×8 chessboard.
- Local two-player alternating turns.
- Basic piece movement geometry, captures, and automatic pawn-to-queen promotion.
- Reset board.

## Important limitations
This is an early playable board prototype, not yet a complete chess rules implementation.
Check/checkmate legality, castling, en passant, move history/undo, Stockfish AI, PGN analysis,
and online multiplayer/server are not implemented yet. The current offline board is two-player
on one device, not an AI opponent.

## Open in Android Studio
1. Install Android Studio.
2. Open this project folder.
3. Let Gradle sync.
4. Run on an Android device or emulator.

Package: `com.neverchess.app`
Version: `0.2.0`
